# Parroto Page Inventory

**Target**: `https://parroto.app/`  
**Scope**: Complete inventory of directly inspected pages and unverified static bundle candidates.  
**Status Legend**:
- `Verified (Public)` — Page loads and core functionality/content is accessible without login.
- `Verified (Partial / Feature-Gated)` — Page shell and public preview/read content load, while primary interactive actions require login or `PRO` subscription.
- `Verified (Auth-Blocked)` — Page cannot be used without authentication (renders login form or opens blocking login modal).
- `Verified (Subscription-Gated)` — Page loads with a `PRO` paywall blocking lesson/deck content.
- `Verified (Error State)` — Intentionally tested error/404 handling.
- `Redirect Verified` — Route redirects to a canonical route.
- `Unverified Static Candidate` — Extracted statically by `analyze_web_bundle`; not directly navigated or appears to be an API endpoint.
